# Product captures

Current captures show the working synthetic prototype in both themes. `order-match-light.jpg` and `order-match-dark.jpg` show real local model results for the alternate supplier wording. The cover and six workflow states come from complete 1363 × 912 px app views rendered at 2× resolution, with only surrounding capture canvas cropped. Original source records and UI content are not repainted.

`scripts/capture-match.html` is a development-only capture layout; Vite does not include it in the production build. Keep the capture tab physically active, park the pointer in its excluded outer margin, verify the full scene heading and loaded fonts, then inspect the saved image. `scripts/refresh-current-media.py` prepares current case assets and retains historical Before images. The case video remains an edited sequence of stills rather than a live interaction recording.
